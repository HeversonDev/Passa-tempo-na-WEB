Pomodoro de 25 min

Um timer de 25 minutos é uma ferramenta usada para medir um intervalo fixo de tempo, geralmente associada à técnica Pomodoro. Ao ser iniciado, ele começa a contagem regressiva a partir de 25 minutos até chegar a zero, indicando o fim de um ciclo de foco ou produtividade. Ele emite um alerta visual ao término, ajudando a manter o controle do tempo durante tarefas ou estudos.

Conversor de Moedas

Um conversor de moedas simples com API limitada é uma ferramenta que permite converter valores entre diferentes moedas com base em taxas de câmbio obtidas de uma API gratuita ou com restrições, como limite de requisições por dia. Ele solicita os dados atualizados da API, realiza o cálculo da conversão e exibe o valor correspondente na moeda desejada, sendo ideal para uso casual.

Relógios

Relógio com Fuso Personalizável. Este projeto apresenta um relógio funcional com duas opções de exibição: digital ou analógico, conforme a preferência do usuário. O relógio vem configurado com o fuso horário do Brasil como padrão, mas permite facilmente alternar entre fusos de diferentes países. Ideal para quem deseja acompanhar o horário local ou internacional de forma prática e visual.
